# Security and publication policy
This is a public repository. Store secret values in approved runtime secret storage; local examples are intentionally empty. Never put secrets in catalog records, demo URLs, Terraform state, client-side code, dashboard variables, screenshots or logs. An approved HTTPS demo URL must require separate authentication and avoid bearer links. Isolate demonstrations from production and use synthetic data and least-privilege principals. Validate TLS; do not disable certificate checks. Review code and assets for customer and internal information before committing. If a credential leaks, revoke/rotate immediately and coordinate removal from history. No public MCP gateway endpoints or proprietary designs until explicitly approved.
