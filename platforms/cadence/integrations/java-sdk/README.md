## Setup checklist
1. Confirm supported product versions, service boundaries and licensing.
2. Provision a dedicated test environment; use scoped credentials, verified TLS and synthetic data.
3. Add reviewed deployment templates with placeholder values in this directory.
4. Validate the demo and require authenticated HTTPS ingress before setting a public demo URL in the catalog.
5. Document cleanup and revoke temporary access.
